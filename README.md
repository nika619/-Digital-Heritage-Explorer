# Digital Heritage Explorer — Virasat Se Vikas Tak

An interactive guide to four landmarks of Lucknow. It pairs each site's history with an embedded Google Maps view, and sets out how digital tools could carry that heritage to the next generation.

## Sites

| Site | Why it matters |
|---|---|
| **Bara Imambara** | Built in 1784, home to one of the world's largest unsupported vaulted halls |
| **Chota Imambara** | The "Palace of Lights", a showcase of Persian-influenced architecture |
| **The Residency** | Battlefield and museum of the 1857 uprising |
| **Hanuman Setu** | Riverside Hanuman temple on the Gomti |

## Features

- Card gallery with photography of each landmark
- Detail modal per site: history, cultural significance, and a "digital impact" idea (interactive timelines, heritage quizzes, AR recreations)
- Embedded Google Maps view for every location
- Responsive layout in plain HTML and CSS, with no build step

## Run it

Open `folder heritage-web-ar/index.html` in a browser.

## Theme

Built for the *Virasat Se Vikas Tak* ("from heritage to development") theme: using technology to make local history accessible and engaging.
